# Agència Catalana de l'Aigua

The raw data was extracted from the [ACA website](https://analisi.transparenciacatalunya.cat/es/Medi-Ambient/Xarxes-de-control-del-medi-consulta-de-l-aigua-i-e/wc95-u57z/about_data).

Besides, some files were created manually:

* *map_reservoirs_ACA.yml* maps the reservoir ID in the ACA database with other reservoir and dam datasets such as the nationary Inventory of Dams and Reservoirs (IDR) or the Global Dam Watch (GDW) dataset.
* *stations.csv* contains the catchmet area (km²) of the gauging stations extracted manually from the [ACA live site](https://aplicacions.aca.gencat.cat/aetr/vishid/#damChartModal).
* *reservoirs.csv* contains the catchmet area (km²) and storage capacity (hm³) of the reservoirs extracted manually from the [ACA live site](https://aplicacions.aca.gencat.cat/aetr/vishid/#damChartModal).

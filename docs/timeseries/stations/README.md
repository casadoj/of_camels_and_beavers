# Station time series

Daily time series related to the gauging stations in CAMELS-ES:

* *discharge_cms*: observed river discharge (cubic meters per second).
* *discharge_mm*: specific river discharge (milimeters).
* *evap_mm*: average basin evaporation (milimeters) computed from the EMO-1 dataset.
* *precip_mm*: average basin precipitation (milimeters) computed from the EMO-1 dataset.
* *temp_degC*: average basin temperature (degrees Celsius) computed from the EMO1-dataset.

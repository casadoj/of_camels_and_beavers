# Station time series

Daily time series related to the reservoirs in BEAVERS-ES:

* *storage_mcm*: observed reservoir storage (million cubic meters).
* *filling*: reservoir filling (-).
* *inflow_cms*: estimated reservoir inflow (cubic meters per second).
* *inflow_mm*: specific reservoir inflow (milimeters).
* *outflow_cms*: observed reservoir outflow (cubic meters per second).
* *outflow_mm*: specific reservoir outflow (milimeters).
* *precip_mm*: average basin precipitation (milimeters) computed from the EMO-1 dataset.
* *temp_degC*: average basin temperature (degrees Celsius) computed from the EMO1-dataset.
* *pet_mm*: average basin potential evapotranspiration (milimeters) computed from the EMO-1 dataset.
